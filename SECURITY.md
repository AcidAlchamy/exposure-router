# Security and privacy reports

If you find a security flaw, or a way this library could expose information
about a person, please report it privately rather than in a public issue.

**How:** open a private report from this repository's **Security** tab
("Report a vulnerability"). Only the maintainer sees it.

Please include what you found, how to reproduce it, and what you think the
impact is. You'll get a reply within a week. Once a fix ships, you'll be
credited, unless you'd rather not be.

**In scope:** anything in `src/`, the bench, the fixtures, and the CI setup.
That includes a fixture that turns out to contain real sensor locations, or a
change to the types that would let them hold data about a person.
